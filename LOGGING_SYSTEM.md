# Results Logging System

## Overview
Comprehensive logging system for tracking AILS-II experiments, essential for RL development and comparison.

## What Gets Logged

### 1. Per-Iteration Data (`iterations.csv`)
Every iteration logs:
- **iteration**: Iteration number
- **time_sec**: Elapsed time in seconds
- **solution_quality**: Current solution objective value
- **gap_percent**: Gap from best known solution (%)
- **num_routes**: Number of routes in solution
- **eta**: Acceptance criterion threshold
- **omega**: Perturbation strength
- **perturbation_type**: Which operator was used (Sequential/Concentric)
- **insertion_heuristic**: Which heuristic was used (Distance/Cost)
- **distance_ls**: Distance after local search
- **improvement**: Improvement from previous best

### 2. Run Summary (`summary.csv`)
One line per run with:
- **run_id**: Timestamp identifier
- **instance**: Problem instance name
- **seed**: Random seed (or "none")
- **stopping_criterion**: Time or Iteration
- **time_limit_or_iterations**: Limit value
- **final_quality**: Final solution quality
- **final_gap**: Final gap (%)
- **best_quality**: Best solution found
- **best_gap**: Best gap achieved (%)
- **total_iterations**: Total iterations completed
- **time_to_best**: Time when best was found (seconds)
- **iter_to_best**: Iteration when best was found
- **total_time**: Total execution time (seconds)

### 3. Configuration (`config.txt`)
Full experiment configuration including:
- All parameters (eta, omega, gamma, varphi, etc.)
- Instance file path
- Random seed
- Timestamp

## Usage

### Running Experiments
```bash
# Single run
java -cp bin SearchMethod.AILSII \
    -file data/XL-n1048-k237.vrp \
    -rounded true \
    -best 380211 \
    -limit 1000 \
    -stoppingCriterion Iteration \
    -seed 42

# Results automatically saved to: experiments/XL-n1048-k237/<timestamp>/
```

### Collecting Baseline Data
```bash
# Run multiple experiments with different seeds
./collect_baseline.sh

# This runs 10 experiments with seeds: 1, 2, 3, 5, 7, 11, 13, 17, 19, 23
# All results saved to: experiments/XL-n1048-k237/
```

### Analyzing Results

#### Single Run Analysis
```bash
python analyze_results.py experiments/XL-n1048-k237/20260205_123456/
```

**Generates**:
- `convergence.png` - Solution quality over time/iterations
- `parameters.png` - Omega, eta, distance, routes evolution
- `operators.png` - Operator selection frequency
- `improvements.png` - Distribution and cumulative improvements
- `report.txt` - Text summary with statistics

#### Multiple Runs Comparison
```bash
python analyze_results.py experiments/XL-n1048-k237/
```

**Generates**:
- `comparison.csv` - Combined summary of all runs
- Statistical comparison (mean, std, min, max gaps)

## For RL Development

### 1. Baseline Collection
```bash
# Collect baseline performance across multiple seeds
./collect_baseline.sh

# Analyze variance
python analyze_results.py experiments/XL-n1048-k237/
```

### 2. Training Data
The `iterations.csv` contains everything needed for RL training:
- **State features**: eta, omega, num_routes, gap, time
- **Actions taken**: perturbation_type, insertion_heuristic
- **Rewards**: improvement, gap reduction

### 3. Comparing Baseline vs RL

```python
import pandas as pd

# Load baseline run
baseline = pd.read_csv('experiments/XL-n1048-k237/baseline_run/iterations.csv')

# Load RL-enhanced run (same seed!)
rl_run = pd.read_csv('experiments/XL-n1048-k237/rl_run/iterations.csv')

# Compare convergence
import matplotlib.pyplot as plt
plt.plot(baseline['iteration'], baseline['gap_percent'], label='Baseline')
plt.plot(rl_run['iteration'], rl_run['gap_percent'], label='RL-Enhanced')
plt.legend()
plt.show()
```

### 4. Operator Performance Analysis
```python
import pandas as pd

# Load all runs for an instance
import glob
all_runs = []
for file in glob.glob('experiments/XL-n1048-k237/*/iterations.csv'):
    all_runs.append(pd.read_csv(file))

combined = pd.concat(all_runs)

# Which operator leads to most improvements?
improving = combined[combined['improvement'] > 0]
print(improving.groupby('perturbation_type')['improvement'].agg(['count', 'mean', 'sum']))

# Which insertion heuristic performs better?
print(improving.groupby('insertion_heuristic')['improvement'].agg(['count', 'mean', 'sum']))
```

## Example Analyses

### 1. Find Iteration Where Gap Drops Below 1%
```python
df = pd.read_csv('experiments/XL-n1048-k237/run/iterations.csv')
first_below_1 = df[df['gap_percent'] < 1.0].iloc[0]
print(f"First below 1% at iteration {first_below_1['iteration']}")
print(f"Time: {first_below_1['time_sec']:.2f}s")
```

### 2. Correlation Between Omega and Improvement
```python
import pandas as pd
import numpy as np

df = pd.read_csv('experiments/XL-n1048-k237/run/iterations.csv')
correlation = np.corrcoef(df['omega'], df['improvement'])[0, 1]
print(f"Correlation between omega and improvement: {correlation:.3f}")
```

### 3. Operator Success Rate
```python
df = pd.read_csv('experiments/XL-n1048-k237/run/iterations.csv')

for op in df['perturbation_type'].unique():
    op_data = df[df['perturbation_type'] == op]
    success_rate = (op_data['improvement'] > 0).mean()
    avg_improvement = op_data[op_data['improvement'] > 0]['improvement'].mean()
    print(f"{op}: {success_rate:.1%} success rate, avg improvement: {avg_improvement:.2f}")
```

## Benefits for RL

1. **Training Data**: Complete trace of states, actions, rewards
2. **Reproducibility**: Every run fully documented with seed
3. **Comparison**: Easy A/B testing (baseline vs RL)
4. **Analysis**: Identify which decisions matter most
5. **Debugging**: Trace exact sequence of decisions
6. **Reporting**: Publication-ready figures and tables
